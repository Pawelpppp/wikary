# wikary
Wikary - retro 16-bit gra w przeglądarce (Phaser 3)

## Bohater
Główną postacią jest **wikary Kamil**: rude krótkie włosy, czarna sutanna, plecak.

## Mechanika
- **Bieg** w lewo i w prawo (strzałki).
- **Skok:** jedno wciśnięcie Spacji = zwykły skok.
- **Skok z saltem:** dwa wciśnięcia Spacji = salto i wyższy skok.
- **Moce:**
  - uderzenie **ogniem**,
  - uderzenie **krzyżem**,
  - **błogosławieństwo krzyżem**,
  - **modlitwa**.

## Grafiki
Assety w `assets/` (skopiowane z Fibi-Run). Nowe grafiki Kamila (bieg, skoki, salto, moce, modlitwa, portret z bliska z otwartymi i zamkniętymi oczami) są w przygotowaniu.
